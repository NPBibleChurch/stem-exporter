Native macOS app

Weekly stems, reduced to a couple of clicks

Stem Exporter turns a folder of multichannel field-recorder WAVs into a folder of named, trimmed, per-track stems — no DAW required.

Download latest release View source on GitHub

Requires macOS 14 (Sonoma) or later.

Everything the weekly export chore needs

Any channel count

Channel count is detected from the files themselves — not hardcoded, so other gear or configurations still work.

Automatic recombining

Split files from long sessions are automatically stitched back into continuous per-track audio.

Saved track templates

Track 1 → "Piano", Track 2 → "Violin" — save a naming template once and reuse it every week.

Stereo-linked pairs

Map tracks like 7+8 to "Overheads L/R" and export them as a single interleaved stereo file.

One trim for the whole session

Cut dead air before and after the service with a single start/end point applied to every stem.

Batch export

Export every resulting stem in one batch, quickly and reliably, to a chosen folder.

How it works

  1. 1

    Add a session folder

    Point the app at a folder of WAVs — one file or many.

  2. 2

    Pick a template and trim

    Choose a saved track name template, then trim the session's start and end.

  3. 3

    Export

    Batch export every named, trimmed stem to a chosen folder.
